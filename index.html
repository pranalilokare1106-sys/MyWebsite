🧠 How the Minimax Algorithm Works (FAI Concepts) ▼

1. Two-Player Zero-Sum Game

Tic-Tac-Toe is modeled as an adversarial game where Computer (O) is the Maximizer aiming for the highest score, and Human (X) is the Minimizer aiming to minimize Computer's score.

2. Terminal Evaluation Function

When the game reaches a terminal state, an evaluation score is calculated:

  • AI Wins: +10 - depth (Rewards faster victories)
  • Player Wins: -10 + depth (Prefers later losses if inevitable)
  • Draw / Tie: 0 (Neutral outcome)

3. Backtracking & Decision Tree

The algorithm recursively investigates every possible legal move, calculates the minimax value of all descendant board configurations, and backtracks to select the optimal root move.

4. Mathematical Invariability

Under optimal play by both participants, Tic-Tac-Toe is a proven mathematical draw. With Minimax active, the AI will never lose; it will either win if the player makes a tactical mistake or draw if the player plays perfectly.
